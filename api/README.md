# API Documentation for BSDO Sale Platform

This directory contains all the REST API endpoints for the BSDO Sale platform. These APIs allow for programmatic access to the platform's functionality including user management, product listings, inquiries, and live streaming features.

## Available Endpoints

- `/api/auth/login` - User authentication
- `/api/auth/register` - User registration
- `/api/auth/logout` - User logout
- `/api/products/list` - Get product listings
- `/api/products/detail` - Get product details
- `/api/users/profile` - Get/update user profile
- `/api/inquiries/create` - Create new inquiries
- `/api/orders/create` - Create new orders
- `/api/live_streams/list` - Get live streams
- `/api/cart/add` - Add item to cart
- `/api/cart/remove` - Remove item from cart
- `/api/cart/list` - List cart items
